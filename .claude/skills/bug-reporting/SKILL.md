# Bug reporting

For each bug report:
- **Title**: short, specific.
- **Steps to reproduce**: numbered, including the script JSON or settings used (attach a minimal script if possible).
- **Expected** and **Actual**.
- **Severity**: critical (crash, data loss, wrong input sent), major (feature broken), minor, cosmetic.
- **Evidence**: failing test name and output, or `file:line` where the cause seems to be.
